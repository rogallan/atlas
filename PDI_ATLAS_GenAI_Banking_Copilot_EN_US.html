ATLAS — Banking GenAI Copilot

Anchor project: build a conversational copilot for a bank relationship manager, able to consult public knowledge from the Central Bank, query a fictitious customer/financial-history database, and execute simple simulated operations through controlled tools. The project is developed locally, with the LLM served via Ollama, and has a path to cloud publishing/infrastructure.

Technical Map & Target Architecture

Architecture contract that guides the four quarters.

FrontEnd

React Chat with streaming, sources, simulation cards, action confirmation, and error handling.

API

FastAPI as the product boundary: simulated authentication, session, streaming, contracts, validation, observability, and security.

Agent

Router → Knowledge/RAG or Query/Action → Validation → Response. Multi-agent only where there's a measurable benefit.

MCP

Decoupled business capabilities: profile, loan, insurance, consortium, tariffs, and ticket.

Knowledge

Public documents → ingestion → chunking → metadata → embeddings → Vector DB/Store → retrieval → citations.

Infra

Local-first: Ollama + containers + Vector DB/Store + MCP. Controlled backend exposure via ngrok. Terraform represents the AWS path.
