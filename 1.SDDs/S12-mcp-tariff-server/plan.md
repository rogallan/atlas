# Plan — S12 · MCP Tariff Server

## 1. Approach

Implement the MCP Tariff Server under `src/mcp/tariff/`. The server provides structured and typed lookups for banking service fees, packages, and regulatory quotas. It acts as a deterministic source of truth for exact figures and rules, complementing RAG (S07) whenever precise numerical fee verification or package comparisons are requested.

## 2. Architecture & Components

```
src/mcp/tariff/
├── __init__.py
├── server.py        # MCP Server entrypoint, transport & tool registrations
├── tools.py         # Handlers: get_service_fee, list_tariff_packages, check_essential_services_quota, compare_packages
├── models.py        # Pydantic schemas (TariffItem, PackageInfo, QuotaCheckResult, Channel)
├── catalog.py       # In-memory structured repository of tariffs and packages
└── sync.py          # Cross-validation helper ensuring consistency with RAG corpus
```

### Flow of Execution:
1. **Tool Invocation:** The Agent Orchestrator (S14) invokes `get_service_fee` or `list_tariff_packages`.
2. **Schema Validation:** `models.py` validates requested service codes, channels, and package identifiers.
3. **Structured Lookup:** `catalog.py` retrieves the itemized fee record, checking channel differentials (counter vs. ATM vs. Internet).
4. **Essential Quota Verification:** If checking mandatory quotas, `check_essential_services_quota` computes remaining free transactions for the calendar month according to BACEN Res. 3.919.
5. **Metadata Enrichment:** Appends regulatory norm references (`norm_reference`, `effective_date`) to the output.
6. **Structured Output:** Emits the typed Pydantic response via MCP JSON-RPC.

## 4. Tariff Catalog Data & Essential Services (BACEN Res. 3.919)

- **Serviços Essenciais Gratuitos (Pessoa Física):**
  - Cartão de débito (fornecimento e 2ª via se não houver culpa do cliente): R$ 0,00.
  - Saques em conta de depósitos: até 4 saques por mês gratuitos.
  - Transferências entre contas da própria instituição: até 2 por mês gratuitas.
  - Fornecimento de extrato com movimentação dos últimos 30 dias: até 2 por mês gratuitos.
  - Consultas via internet: ilimitadas / R$ 0,00.
- **Serviços Diferenciados:**
  - TED/DOC presencial vs. digital.
  - Folhas de cheque avulsas.
  - Pacotes padronizados I, II, III e IV conforme regulamentação BACEN.

## 5. Test Strategy

- **Catalog Completeness Tests:** Ensure all required standard banking services are defined with positive or zero prices.
- **Essential Services Test:** Verify that queries for essential services always return zero charge within the 4-withdrawal / 2-transfer / 2-statement limits.
- **Channel Differential Tests:** Verify price differences between branch counter and self-service/digital channels.
- **Cross-Consistency Tests:** Run comparison assertions between `catalog.py` figures and the BACEN tariff markdown files indexed in RAG (S06/S07).
- **Validation Tests:** Invalid service code or malformed channel returns typed validation error.

## 6. Risks & Mitigations

- **Risk:** Contradiction between text generated by RAG and structured numbers returned by MCP Tariff Server.
  - **Mitigation:** The Agent Orchestrator policy prioritizes MCP Tariff Server for exact numeric pricing, using RAG for conceptual explanation of rights and rules.
- **Risk:** Outdated tariff tables.
  - **Mitigation:** Version and timestamp all catalog entries with `effective_date` and document currency update in repository fixtures.
