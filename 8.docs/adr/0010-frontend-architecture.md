# ADR 0010: Frontend Architecture (Next.js 15, React 19, Tailwind CSS, SSE Streaming)

## Status
Accepted

## Date
2026-10-11

## Context
Per `1.SDDs/S15-react-chat/spec.md`, the relationship manager requires an intuitive, fast, and responsive user interface to interact with the copilot.
Requirements:
1. Low-latency token streaming for natural LLM conversation.
2. Interactive widgets for financial simulations (amortization tables, installment sliders).
3. Human-in-the-Loop action confirmation cards.
4. Embedded observability and metric visualizations.
5. Modern, production-grade styling with dark mode and zero UI bloat.

## Decision
Selected **Next.js 15 App Router** with **React 19** and **Tailwind CSS**:
1. **Server-Sent Events (SSE) Client:** Implemented asynchronous streaming hooks consuming the `/v1/chat/stream` API endpoint, rendering words as they are generated by the model.
2. **Modular Banking Components:**
   - `ChatWindow`: Main conversational interface with citation badges and collapsible sources.
   - `SimulationCard`: Interactive rendering of Loan (Price/SAC), Insurance, and Consortium breakdowns.
   - `HITLConfirmationModal`: Visual confirmation prompt for support tickets and limit approvals.
   - `MetricsDashboard`: Real-time operational graphs and token statistics.
3. **Deployment Target:** Hosted and continuously delivered via **Vercel** with automatic preview deployments and edge routing.

## Consequences
- **Positive:**
  - Rich user experience with instantaneous visual feedback via SSE streaming.
  - Zero-configuration hosting on Vercel with global CDN caching.
  - Reusable component architecture in TypeScript.
- **Negative / Mitigations:**
  - Separate Node.js development environment alongside the Python backend.
  - Mitigated by providing clear `npm run dev` scripts and unified Docker compose orchestration.
