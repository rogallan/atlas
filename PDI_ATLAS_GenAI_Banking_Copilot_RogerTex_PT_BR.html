ATLAS — Banking GenAI Copilot

Projeto âncora: construir um copiloto conversacional para um gerente bancário, capaz de consultar conhecimento público do Banco Central, consultar uma base fictícia de clientes/histórico financeiro e executar operações simples simuladas por ferramentas controladas. O projeto será desenvolvido localmente, com LLM via Ollama, e terá caminho de publicação/infra em cloud.

Mapa técnico e arquitetura alvo

Contrato de arquitetura que guia os quatro trimestres.

FrontEnd

React Chat com streaming, fontes, cards de simulação, confirmação de ações e tratamento de erros.

API

FastAPI como fronteira do produto: autenticação simulada, sessão, streaming, contratos, validação, observabilidade e segurança.

Agent

Router → Knowledge/RAG ou Query/Action → Validation → Response. Multiagente somente onde houver benefício mensurável.

MCP

Capacidades de negócio desacopladas: perfil, empréstimo, seguro, consórcio, tarifas e ticket.

Knowledge

Documentos públicos → ingestão → chunking → metadata → embeddings → Vector DB/Store → retrieval → citações.

Infra

Local-first: Ollama + containers + Vector DB/Store + MCP. Exposição controlada do backend via ngrok. Terraform representa o caminho AWS.

Estrutura de projeto proposta

Layout de repositório que sustenta o padrão SDD: a pasta raiz SDDs/ recebe um subdiretório por item do catálogo (seção 14, S00 → S22), cada um com spec/plan/tasks/verify.

atlas/
├── SDDs/                   # Um subdiretório por item do catálogo SDD (S00 → S22)
│   ├── S00-constitution/
│   │   ├── spec.md
│   │   ├── plan.md
│   │   ├── tasks.md
│   │   └── verify.md
│   ├── S01-toolchain-python/
│   ├── S02-base-sintetica-clientes/
│   ├── S03-fastapi-gateway/
│   ├── ...
│   └── S22-release-portfolio/    # cada pasta segue o mesmo padrão spec/plan/tasks/verify
├── docs/
│   ├── adr/               # Architecture Decision Records
│   └── runbooks/
├── src/
│   ├── api/                # FastAPI: rotas, contratos, streaming, auth simulada
│   ├── agent/               # Router, Validator/Critic, grafo do agente
│   ├── rag/                 # Ingestão, chunking, embeddings, retrieval
│   ├── mcp/                  # MCP Servers: perfil, empréstimo, seguro, consórcio, tarifas, ticket
│   ├── providers/             # Adapter Ollama (LLM local)
│   └── data/                  # Modelos sintéticos de cliente/histórico + seed
├── frontend/                  # React Chat (publicado na Vercel)
├── infra/
│   ├── docker/                # docker-compose (API, MCP, Vector, Ollama)
│   └── terraform/             # Módulos AWS (network, compute, data, observability)
├── evals/                     # Harness, golden dataset, golden conversations, scorecards
├── tests/                     # Unitários, integração, contrato e segurança
└── ops/                       # Observabilidade: logs, traces, correlation ID
